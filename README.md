# Sallve Skin AI — versão mobile

Abra `abrir.html` ou `index.html`.

No iPhone:
1. Abra o arquivo em um navegador/editor que permita visualizar HTML.
2. Toque em Compartilhar.
3. Escolha "Adicionar à Tela de Início" quando essa opção estiver disponível.

O projeto é um protótipo conceitual e não é um aplicativo oficial da Sallve.
